# Project Report: Lahore Fresh Bakes

## 1. Business Problem

Lahore Fresh Bakes is a small local bakery. Customers usually need to call or visit the shop to ask about cakes, breads, prices, and custom orders. This takes extra time for the customer and also makes order handling difficult for the bakery owner.

## 2. Proposed Solution

For this problem, I made a 4-page website using PHP and MySQL. The website has Home, About, Products, and Contact pages. Customers can see bakery products and send a message through the contact form. The bakery owner can log in to the admin panel and manage products.

The admin panel includes add, edit, and delete options for products. It also supports product image upload. The database has separate tables for admins, categories, products, and customer messages. Products are connected with categories through a foreign key.

## 3. AI Tools Used

I used AI tools for help with layout ideas, checking code errors, and improving some content. The main project was then arranged according to the final project requirements.

## 4. Challenges Faced

The main challenge was connecting the website with MySQL instead of keeping it as only static pages. Image upload also needed care because the file type and size should be checked. The admin login was another important part because product management should not be open to every visitor.

## 5. Conclusion

This project gives Lahore Fresh Bakes a simple website and admin panel. It includes PHP, MySQL, product CRUD, image upload, contact form, and a database export file.
